# 🌟 Motivational Planner  
A productivity web app designed to help you organize tasks, stay motivated with quotes, and track your progress — all wrapped inside a beautiful UI with clocks, timers, and inspirational messages.

Live Website: **https://motivational-planner.onrender.com/main.html**

---

## 🚀 Features

### ✅ Task Management  
- Add, edit, delete, and track tasks  
- View completed tasks  
- Simple and clean interface  

### 🕒 Countdown Timer  
- Built-in task timer  
- Helps you focus using time-blocking  
- Audio/visual alert when time ends  

### 🕰 Motivational Clock  
- Custom-designed analog canvas clock on the homepage  
- Adds personality and creativity to the UI  

### 💬 Motivational Quotes  
- Inspiring quotes displayed automatically  
- Changes when refreshing the page  
- Helps boost mood and productivity  

### 🎴 Flip Landing Page  
- Beautiful front-and-back card flip animation  
- Front: clock + quote  
- Back: steps on how to use the app and the “Enter Main App” button
